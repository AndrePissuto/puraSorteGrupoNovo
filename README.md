🏇 TURF – Simulador de Corrida de Cavalos
📌 Sobre o projeto

O TURF é um projeto desenvolvido na disciplina de Algoritmos, com o objetivo de aplicar conceitos fundamentais de programação, como:
Estruturas de repetição
Vetores (arrays)
Condições (if/else)
Funções
Manipulação do DOM (HTML + JavaScript)
Eventos de clique
Armazenamento temporário de dados

O sistema simula uma corrida de cavalos virtual, onde o usuário define a quantidade de cavalos e voltas, 
cadastra os nomes dos participantes e acompanha o resultado da corrida em tempo real.

Conceitos aplicados
Vetores para armazenar os cavalos e resultados
Funções para organizar a lógica do sistema
Laços de repetição para simular as voltas da corrida
Geração de números aleatórios para simular velocidade
Ordenação de dados para montar o ranking
Manipulação do HTML com JavaScript
